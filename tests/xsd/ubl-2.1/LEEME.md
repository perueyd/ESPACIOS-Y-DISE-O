# Esquemas XSD de UBL 2.1

Esquemas oficiales de OASIS UBL 2.1 (Invoice, CreditNote, DebitNote y componentes
comunes), usados por las pruebas para validar que los XML generados tengan la
estructura correcta. Copiados sin cambios del repositorio abierto
`thegreenter/ubl-validator` (carpeta `src/xsd/2.1`), oct-2026.

Estos esquemas validan la ESTRUCTURA. Las reglas propias de SUNAT (catálogos,
cálculos, tolerancias) se validan al enviar a SUNAT beta (fase 4).
